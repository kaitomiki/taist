# 都立AI スタジオ

ZIP全体を展開して ToritsuStudio.exe を起動します。最初に「生徒として始める」か「先生として始める」を選びます。

## 生徒が作品を作る

1. **保存場所**で授業用のフォルダーを選び、「次へ」を押します。
2. **作品の種類**を選びます。Webページは index.html、JavaScriptは main.js、Pythonは main.py から始まります。同名ファイルがあれば続きから開きます。別の作品を再開するときは「すでにあるファイルを開く」を選びます。
3. **AIと教室**でモードを選び、都立AIのAPIキーを貼り付けます。「Bearer 」付きで入力できます。

### Teach（授業）

先生から配られたGist教室リンクを登録し、授業の指示を受信してから制作を始めます。制作中もAIへの依頼前に指示を再取得します。

1. 画面上部の「AIへのお願い」に希望を書き、「① 方針を相談」を押します。
2. 方針を変えたいときは同じ欄に追加の希望を書き、「方針に追記」を押します。何度でも更新できます。
3. 「構成案に進む」で工程を読み、「構成を確定して実装」で一工程を作ります。
4. 編集欄の変更案を確認します。「承認」で対象ファイルと内容を確認して保存します。「却下」でその変更案を破棄し、「AIへのお願い」に修正点を書いて同じ工程を再生成できます。
5. 最終工程を承認すると、実際に承認したコードの抜粋と授業の指示を使って、得られた学び・動作の理由・次に試せることをAIがまとめます。

「AIの解説」でコード理解、エラー確認、問題分解、段階的なヒント、完成例を選べます。

### Create（自宅・自由制作）

Createでは準備画面で都立AIのAPIキー入力が必須です。キーを貼り付けると「制作を始める」が押せます。教室への参加は不要です。制作室では、作品の希望を書いて「作品をまとめて作る」を押します。選んだファイルと必要な追加ファイルを一度に提案します。既存の関連コードも変更対象にするには「AI設定」で関連コードの送信を選びます。実装に挿絵が必要なときは設定で画像生成を許可できます。

「承認」画面ではファイル名を切り替えて内容を確認できます。「承認して保存」で作品をまとめて保存し、最後に学習の振り返りを生成します。「却下」した変更案と挿絵は作品フォルダーに書き込まれません。新しい指示を加えて再生成できます。振り返りの通信に失敗した場合は解説欄の「振り返り」で再試行できます。

TeachとCreateは淡い青紫の共通画面です。上部に現在の段階と次の操作を表示します。Createは中央に「AIへのお願い」「AIの回答・解説」と実行ログ、右側に縦長のコードエディタがあります。上部の ▶ を押すと独立した実行パネルが開き、「実行」で保存版を試せます。パネルの閉じるボタンは表示を隠し、■ は実行を停止します。アイコンにマウスを合わせると操作名を表示します。Teachは右側の固定プレビューで実行します。

### 拡大して作業する

コードエディタ、実行ログ、Teachの実行・解説の「拡大」を押すと、その領域を制作室いっぱいに表示します。「元に戻す」または Esc で戻ります。プレビューの実行状態と編集中の内容を引き継ぎます。

### コードの表示とプレビュー

コード欄はHTML、Python、JavaScriptのキーワード・文字列・コメントなどを色分けします。保存後、右の「実行プレビュー」で試せます。JavaScriptはアプリ内のWebView2で実行します。ブラウザーのモジュール、DOM、相対import、console.logに対応します。Pythonの入力はプレビュー下の欄から送信します。

同梱ソフトの表示・利用条件は licence.txt に収録しています。生成時も外部ライブラリを使う場合は名称・版・出典・ライセンス・原文表示をAIに求め、申告された依存関係を作品の licence.txt にまとめて承認画面に表示します。AIの申告や原文の正確性は、配布前に各出典と確認してください。
## 先生が授業の指示を配る

1. 「教室を作る」を押し、教室名とAIに守ってほしい授業の指示を入力します。
2. 「次へ」でGitHubトークンを入力します。初めての方は画面のボタンからGitHubで gist 権限付きトークンを発行できます。「この内容で配信」を押します。
3. 「リンクをコピー」を押し、生徒へ共有します。

授業の内容を入力する画面の「左側に表示するヒント」に最大2000文字で入力して配信すると、同じGistの hints.txt が更新されます。授業の指示は classroom.txt に保存されます。ヒント欄が空なら標準文を配信します。

Teachでは参加した教室のヒントを左に表示します。Createでも「教室のヒント」から教室リンクまたはGitHub Gistのリンクを登録できます。登録済みのヒントは起動時・3分ごとに取得します。Teachの「ヒントを更新」で手動更新もできます。配信側のキャッシュによって反映が遅れる場合があります。

途中で指示を変えるときは、一覧から教室を選び「指示・ヒントを変更」を押します。生徒の次の生成時に指示を取得します。配信キャッシュによって反映に数分かかる場合があります。GitHubトークンは生徒に共有せず、教室リンクだけを配ります。

Windows 11 Arm64用。HTMLプレビューにはMicrosoft Edge WebView2 Runtimeを使用し、Python 3.13.9 Arm64は同梱しています。都立AIのコード・画像APIはキーごと・Windowsユーザーごとに送信を合算し、501回目から新しいキーを求めます。







## Teach の教室
先生は「教室を作る」または「指示・ヒントを変更」を開き、「モード・単元」で授業形式を選びます。単元は1行ずつ入力し、ドリルで単元に加点する場合は「条件分岐|2」と書きます。加点は0～20です。教室設定は同じGistの course.json に保存されます。生徒は最初にTeachを選び、先生から受け取った教室リンクを登録します。Createまたは作品制作の教室を選んだ場合に、保存場所と作品の種類を指定します。

ラーニングは番号で単元を選び、基礎説明、コード例、出力例、例題、応用問題の順に進みます。ドリルは選択した単元から1問ずつ出題します。AIが提出内容を判定し、誤答時はヒントを表示します。難易度は3段階で、正解すると難易度の1～3点と単元加点が入ります。5点ごとにレベルが上がります。同じ結果が2回続くと次の新問の難易度が1段階変わります。正答率は再挑戦を含む全判定を対象に集計し、成績はWindowsのユーザーごと・教室ごとにこの端末に保存します。

作品制作はCreateと同じ手順で、先生がGistで配信する授業の指示を制作依頼に追加します。モード設定のない以前の教室も作品制作として利用できます。
生徒は各モードの「教室を変更」から、最近参加した教室を選ぶか、新しい教室リンクを貼り付けて移動できます。参加履歴はこの端末に直近20件を保存します。

生徒のモード選択画面とドリル内の「ドリル成績」から、教室別の記録と全教室の生涯ポイントを確認できます。成績の閲覧にAPIキーは不要です。
